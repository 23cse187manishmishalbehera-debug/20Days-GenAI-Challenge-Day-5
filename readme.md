
# 😂 AI Joke Generator using Groq API

## 🚀 Project Overview
AI Joke Generator is a simple Generative AI project built using Python and Groq API.  
The application generates funny jokes instantly based on the topic entered by the user.

Examples:
- Coding jokes 💻
- AI jokes 🤖
- School jokes 🏫
- Sports jokes ⚽

---

## 🛠️ Features

- AI-generated jokes
- User topic input
- Fast responses using Groq API
- Beginner-friendly project
- Uses Prompt Engineering
